01 / THE QUESTION

Where would a source build enter your install?

Supply an existing environment or exact-pinned requirements export. The checker inspects all recorded versions, including transitive dependencies, without choosing versions or building packages.

03 / READ THE RESULT

Know what a
“wheel found” means.

The repaired checker asks whether each recorded exact version has a compatible wheel for the running interpreter. It uses recorded dependency metadata; it does not guarantee an install or scan for malware.

This repair is unreleased; published 1.0.11 can report false success. See the guide for supported inputs, extras and metadata limitations. Keep --only-binary :all: enabled for installs.
